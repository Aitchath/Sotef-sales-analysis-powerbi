# Analyse des performances commerciales - SOTEF

 ## Présentation

Ce projet consiste à analyser les performances commerciales de l'entreprise fictive SOTEF, spécialisée dans la vente de :

    - Mobilier
    - Fournitures
    - Technologie

L'objectif est de construire un tableau de bord interactif permettant à la direction de suivre rapidement l'activité commerciale et d'identifier les leviers de performance.

 ## Objectifs du projet
   ### Construire un dashboard clair et interactif

   #### Suivre les indicateurs clés :

            - Chiffre d'affaires
            - Marge
            - Nombre de commandes
            - Panier moyen
   #### Analyser les ventes :

            - Par région
            - Par catégorie
            - Dans le temps
   #### Faciliter la prise de décision grâce à des visualisations dynamiques

 ## Outils utilisés
   #### Power BI Desktop
            - Modélisation des données
            - Création des visualisations
            - Construction des dashboards
   #### Power Query
            - Nettoyage des données
            - Correction des types
            - Gestion des incohérences
   #### DAX
            - Création des KPI
            - Mesures calculées
            - Indicateurs métiers

 ## Méthodologie

   ### Importation des données 
        Chargement des données dans Power BI.

   ### Nettoyage 
        - Vérification des types de données
        - Correction des formats 
        - Traitement des incohérences

   ### Modélisation 
        - Création des mesures DAX :
        - Chiffre d'affaires
        - Marge
        - Nombre de commandes
        - Panier moyen

   ### Design
        - Création d'une identité visuelle cohérente :
        - Couleurs personnalisées
        - Cartes KPI
        - Fond graphique

   ### Visualisation
        Création des graphiques et tableaux de bord.

   ### Interactivité
        Ajout de filtres :
            - Année
            - Région
            - Catégorie
            - Mode de livraison
